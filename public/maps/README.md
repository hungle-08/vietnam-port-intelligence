# Vietnam reference geometry

Natural Earth 1:50m Admin 0 Countries, filtered to `ADM0_A3=VNM`. Properties reduced to the country name; geometry retained.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

License: public domain, https://www.naturalearthdata.com/about/terms-of-use/

This simplified reference geometry follows the source dataset, including its boundary conventions. It is not a navigational or cadastral map and does not establish maritime sovereignty.
