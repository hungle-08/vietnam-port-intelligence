# Các mẫu icon tàu SVG

- **A — Tàu container phối cảnh:** Gần với mẫu đang dùng; có chiều sâu. [a-ship.svg](a-ship.svg)
- **B — Tàu nhìn từ trên xuống:** Gọn, phù hợp bản đồ và hướng di chuyển. [b-ship.svg](b-ship.svg)
- **C — Tàu container ngang:** Dễ nhận diện, rõ cả ở kích thước nhỏ. [c-ship.svg](c-ship.svg)
- **D — Nét viền tối giản:** Nhẹ, ít chi tiết, hợp giao diện tinh gọn. [d-ship.svg](d-ship.svg)
- **E — Tàu công nghệ neon:** Nổi bật với đường sáng và các điểm tín hiệu. [e-ship.svg](e-ship.svg)
- **F — Silhouette một màu:** Rất gọn, dễ phối màu với đường nối. [f-ship.svg](f-ship.svg)

Các mẫu dùng để lựa chọn phong cách minh họa trên bản đồ; chưa thay đổi icon trong ứng dụng.
